# Store Sales Analysis Project

## Overview

This project is a sales data analysis system built with Python.

The program reads data from CSV files, cleans the data, stores information in SQLite, and creates charts for analysis.

## Technologies Used

- Python
- Pandas
- Matplotlib
- SQLite
- SQL
- OOP (Object-Oriented Programming)
